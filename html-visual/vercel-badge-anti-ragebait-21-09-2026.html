TẦNG 2: COMPONENT & DOM STRUCTURE

Cấu Trúc DOM Của Badge & Warning Boxes

Badge được tái cấu trúc thành component tối giản: thẻ span text + thẻ span confidence dùng Geist Mono.

Monk Mode và Scam Warning box cũng được cấu trúc thành 2 tầng rõ rệt: icon + tiêu đề đậm + mô tả chi tiết, dùng chung class CSS.

TẦNG 3: CALL TREE & PIPELINE

Luồng Xử Lý Phân Loại & Gán Badge

Khi quét bài viết, luồng chạy qua checkAndApplyMonkMode, gửi batch lên API classifier.dev, nhận scores và dispatch qua renderClassification.

Hàm getDisplayLabelName chịu trách nhiệm chuẩn hóa tên sang đúng 1 từ tiếng Anh trước khi nhét vào DOM. 

scheduleScan (150ms debounce)
  └── scanAndProcess()
        ├── checkAndApplyMonkMode(postEl) -> nếu dính goon-bait: ẩn media, render .x-monk-warning-box
        ├── extractContent(postEl) -> textCache deduplication
        └── flushQueue (80ms batch)
              └── sendToClassifierAPI() -> fetchWithRetry / classifier.dev
                    └── renderClassification(item, res)
                          ├── [Priority 1] Scam check -> .x-jev-scam-box
                          ├── [Priority 2] Rage check -> .x-jev-warning-box
                          ├── [Priority 3] Seeding check -> .x-jev-seeding-collapsed
                          └── [Badges] selectMultiBadges()
                                ├── filter(score >= confidenceThreshold)
                                ├── sortDescending()
                                ├── slice(0, 4) -> Top 4 Badges Max
                                └── badge.append(getDisplayLabelName(label))
TẦNG 4: ALGORITHM & TEST GATING

Thuật Toán Kiểm Tra Regex & Retry An Toàn

Bổ sung test assertion bắt buộc: tất cả các label đều phải thỏa mãn regex /^[A-Za-z]+$/ (chỉ gồm các chữ cái tiếng Anh, không chứa dấu cách hay ký tự lạ).

Bọc cơ chế fetchWithRetry với AbortController để đảm bảo test suite chạy trên Bun luôn luôn ổn định và không bao giờ bị timeout mạng. 

  // Thuật toán kiểm tra 1 từ tiếng Anh trong test/classifier.test.js:
  test("Taxonomy structure has all 7 labels with corresponding badges", () => {
    expect(LABELS.length).toBe(7);
    for (const label of LABELS) {
      expect(BADGE_MAP[label]).toBeDefined();
+     // Bắt buộc 1 từ tiếng Anh duy nhất: không khoảng trắng, không tiếng Việt, không emoji
+     expect(BADGE_MAP[label].text).toMatch(/^[A-Za-z]+$/);
    }
  });

  // Helper fetchWithRetry:
  async function fetchWithRetry(url, options, retries = 3) {
    for (let i = 0; i <= retries; i++) {
      try {
        const controller = new AbortController();
        const timer = setTimeout(() => controller.abort(), 12000);
        const res = await fetch(url, { ...options, signal: controller.signal });
        clearTimeout(timer);
        if (res.ok) return res;
      } catch (err) {
        if (i === retries) throw err;
        await new Promise(r => setTimeout(r, 600));
      }
    }
  }
