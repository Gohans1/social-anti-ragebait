📁 1. Kiến Trúc & Data Model

Mô hình lưu trữ của `customLabels` trong Chrome Storage được mở rộng thêm trường instruction?: string.

Đảm bảo 100% tương thích ngược: Các nhãn dạng chuỗi cũ (string) hoặc object không có instruction vẫn chạy trơn tru mà không cần migration phức tạp.

Backward-Compatible Storage Sync
TS TYPE
export interface CustomLabel {
name: string;// Tên nhãn (tối đa 40 ký tự)
action: 'show' | 'hide' | 'off';// 3-state control
+ instruction?: string;// Tiêu chí định hướng phân loại riêng cho Jev AI
}

⚙️ 4. Thuật Toán Auto-Fallback An Toàn

Trọng tâm của tính năng nằm ở khâu kiểm tra chuỗi instruction trong content.js và social-anti-ragebait.user.js.

Nếu người dùng nhập chuỗi trắng (toàn khoảng trắng hoặc rỗng), hệ thống lập tức trỏ về template mặc định. Xóa bỏ hoàn toàn nguy cơ prompt bị rỗng hoặc lỗi cú pháp.

Zero Regression Strict Fallback

if (enabled && !isDuplicate) {

+ const userInstruct = typeof c === 'object' ? (c?.instruction || '').trim() : '';

instructionsList.push(`"${name}": ${finalInstruct}`);
