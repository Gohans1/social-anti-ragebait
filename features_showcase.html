Architecture & Data Flow (Call Tree)

Execution lifecycle from initial page load or DOM mutation to sanitized UI rendering:

scheduleScan (content.js: Debounced 150ms)
  scanPosts
    checkAndApplyMonkMode (0ms Instant Client-side Regex + Meta AI Alt-tags)
    collectUnscannedItems (Filter unscanned post and comment text)
      flushQueue (Debounced 80ms, batch dispatch)
        callJevBatch
          chrome.runtime.sendMessage (Service Worker background CSP bypass)
            fetch('https://classifier.dev/classify') (Zero-shot AI)
              renderClassification
                applyStateToDOM (Blur harmful content, attach warning banner, collapse seeding)
                updatePill (Update stats counters on floating overlay widget)
